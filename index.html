About Vornika

Vornika+- began as an independently developed creative initiative. As it considered its next stage of growth, Vornika recognised that The Choco Studios (TCS) explores a broad range of ideas across different fields. Vornika believed that joining this wider ecosystem could bring fresh perspectives and more room for its own creative direction to develop. It therefore voluntarily proposed joining TCS and now serves as its dedicated game-development unit, while keeping the Vornika name, logo, tagline, and creative identity.

Our place in TCS

Vornika is an internal game-development unit within the TCS ecosystem. When TCS pursues a game project, Vornika is the dedicated game-focused branch that helps initiate and develop it. Its integration was proposed voluntarily by Vornika itself.

What we build

The focus is on games that run directly in a web browser and desktop applications distributed as .exe files for Windows. Projects are developed within TCS, with attention to controls, performance, and the details that shape the experience.

How we work

Explore an idea, build a playable experience, then refine it through testing and iteration. The process stays practical and open to learning, with each improvement guided by what the project actually needs.

Projects

Flappy Bird

The first game project submitted for the Vornika branch of TCS. This single-file browser implementation includes touch and keyboard controls, score tracking, a locally saved best score, and generated sound effects. It is the starting point for Vornika game development within TCS.

Play Flappy Bird

Proyek game pertama yang diserahkan untuk cabang Vornika di TCS. Implementasi browser satu file ini sudah memiliki kontrol sentuh dan keyboard, pencatatan skor, best-score lokal, serta efek suara hasil generate. Ini menjadi titik awal pengembangan game Vornika di dalam TCS.
