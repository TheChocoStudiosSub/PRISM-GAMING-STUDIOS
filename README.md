# Vornika+-

**Play Beyond the Ordinary.**

Vornika+- (Vornika) began as an independently developed creative initiative. It later voluntarily joined The Choco Studios (TCS) and now serves as TCS's dedicated game-development unit while retaining its name, logo, tagline, and creative identity.

## Identity

- **Name:** Vornika+-
- **Short name:** Vornika
- **Previous name:** Prism Gaming Studios (historical name)
- **Tagline:** Play Beyond the Ordinary.
- **Role:** TCS ecosystem unit for game development, integrated from an independent origin
- **Product focus:** Browser games and Windows desktop applications
- **Source licensing:** No open-source license is currently declared in this repository.

## Relationship with The Choco Studios

Vornika+- began as an independent creative initiative. It voluntarily approached TCS because it recognised the breadth of TCS's ideas and its exploration across different creative and technical fields. It now operates as the dedicated game-development unit within the TCS ecosystem.

Describe Vornika as a TCS game-development unit that voluntarily joined from an independent origin. Do not describe it as a unit created by TCS or as an external partner.

## Project

### Flappy Bird — first Vornika game project under TCS

The repository includes a single-file browser implementation of Flappy Bird. The current HTML file includes touch and keyboard controls, score tracking, a locally saved best score, and generated sound effects.

This is an initial browser game project, not evidence of a completed game catalogue or a separate Windows release.

## Repository access and source rights

**GitHub currently reports this repository as Public (checked 24 November 2026).** The source files are therefore publicly readable. However, the repository does not declare an open-source license, so public visibility must not be interpreted as permission to copy, modify, redistribute, or commercially use the code.

There is no public contribution process. Contributions and official releases remain under TCS review and control. If Vornika's source is intended to remain inaccessible to the public, the repository visibility must be changed to Private in GitHub repository settings; that account-level setting is not changed by this branch.
